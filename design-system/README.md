# Lazee Kit Design System

This folder defines the visual and interaction language for Lazee Kit proposal artifacts, demo MVP, pitch deck, and future product site.

The design principle is:

> Friendly first touch, serious protocol layer.

Lazee Kit should make C-address onboarding feel easy and safe for users, while still giving SCF reviewers and Stellar developers confidence that the system is technically credible.

## Core Mood

- Soft mascot onboarding
- Pastel cream, pink, sky, lemon
- Thick sticker outlines
- Rounded UI
- Clean protocol proof cards
- Clear risk and permission language

## What To Avoid

- Generic crypto gradients
- Dark institutional DeFi as the default mood
- Stock imagery
- Abstract 3D coins as primary visuals
- Mascots replacing technical proof
- Overly childish copy
