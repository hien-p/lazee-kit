# Page And Demo Templates

## Proposal Landing Page

First viewport:

- Lazee Kit wordmark
- Headline: "C-address onboarding, made embeddable"
- Subcopy: "Passkeys, sponsored first actions, gift links, and scoped sessions for Stellar apps."
- CTAs: "Watch demo" and "Read proposal"
- Lazee Sun hero mascot
- Proof pills: RFP Track, Open source, Sponsored first action, Passkey UX

## RFP Fit Page

Layout:

- Left column: SCF requirement
- Right column: Lazee response
- Bottom: proof artifact required

Use green check stickers for strong current fit and orange planned stickers for later milestone scope.

## Demo MVP Page

Step timeline:

1. Create C-address
2. Sponsor first action
3. Create gift
4. Claim gift
5. View receipt
6. Grant scoped session
7. Revoke session

Each step should have one screenshot/card and one plain-English outcome.

## Architecture Page

Use Protocol Mode:

- Cream background
- White proof cards
- Ink text
- Clear diagrams
- Trust boundary labels
- Minimal mascot usage

Must show:

- user authorization
- sponsor relay
- contracts
- indexer
- SDK/UI
- optional providers

## Milestone Page

Use three large tranche cards:

- M1 Demo MVP
- M2 Developer Kit
- M3 Production Pilot

Each card includes:

- timeline
- amount
- deliverables
- reviewer verification artifacts
