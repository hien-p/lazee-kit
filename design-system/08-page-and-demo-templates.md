# Page And Demo Templates

## Proposal Landing Page

First viewport:

- Lazee Kit wordmark
- Headline: "Sponsored first actions, made embeddable"
- Subcopy: "Sponsor helper, SDK/UI components, receipts, docs, tests, and runbooks for Stellar apps."
- CTAs: "Watch demo" and "Read proposal"
- Lazee Sun hero mascot
- Proof pills: Open Track, Open source, Sponsored first action, Real receipts, SDK/UI kit

## Build Fit Page

Layout:

- Left column: SCF requirement
- Right column: Lazee response
- Bottom: proof artifact required

Use green check stickers for strong current fit and orange planned stickers for later milestone scope.

## Demo MVP Page

Step timeline:

1. Approve one clear action
2. Sponsor and submit
3. View receipt

Each step should have one screenshot/card and one plain-English outcome.

## Architecture Page

Use Protocol Mode:

- Cream background
- White proof cards
- Ink text
- Clear diagrams
- Trust boundary labels
- Minimal mascot usage

Must show:

- user approval
- sponsor helper
- Stellar RPC / Horizon
- SDK/UI
- receipt status
- observability and runbooks

## Milestone Page

Use three large tranche cards:

- M1 Sponsored First-Action MVP
- M2 Developer Kit
- M3 Testnet Release and Maintenance Package

Each card includes:

- timeline
- amount
- deliverables
- reviewer verification artifacts
