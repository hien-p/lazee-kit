# Reference Analysis

## Reference Mood

The provided visual reference uses a soft sticker interface style:

- Pastel blue, pink, cream, and muted gray panels
- Large rounded character blocks
- Cute mascot with expressive eyes
- Thick white sticker outlines
- Soft shadows and gentle blur
- Rounded icon grid
- Tilted mobile/app cards for product storytelling

## Design Extraction

Colors:

- Soft sky blue
- Candy pink
- Cream/off-white
- Warm yellow
- Ink black
- Muted panel blue-gray

Shapes:

- Large radii
- Blob-like stickers
- Rounded square app icons
- Thick outline treatment

Depth:

- Soft drop shadows
- Subtle background motifs
- Foreground sticker elements

Tone:

- Friendly, playful, approachable
- Not corporate
- Not sharp or aggressive

## Lazee Adaptation

The reference should inspire the feel, not be copied.

- Mascot becomes **Lazee Sun**.
- Stickers become Stellar-specific flow icons.
- Pink cards become demo steps.
- Muted blue icon grid becomes RFP fit/proof grid.
- Cream scenes become proposal and dashboard backgrounds.
