# Icon And Sticker System

## Style Rules

- Thick white outer stroke: 3-4px
- Colored inner stroke: 2px
- Rounded simple geometry
- Soft inner gradient
- Minimal details
- One metaphor per icon
- Transparent background when exported as asset

## Icon Grid

Use muted blue panel background `#EEF3FF`, rounded square cells, 20-24px radius, and subtle white borders. Icons should feel like collectible stickers but remain legible at 48px.
