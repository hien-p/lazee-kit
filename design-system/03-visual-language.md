# Visual Language

## Two Modes

Lazee Kit uses two modes that share tokens but differ in density and tone.

## Play Mode

Use for onboarding, hero, gift links, claim flows, success states, and demo moments.

Traits:

- Pastel backgrounds
- Mascot present
- Sticker icons
- Large rounded cards
- Friendly copy
- Minimal jargon
- Visible progress steps

Example sections:

- "Create with passkey"
- "Your first action is sponsored"
- "Claim USDC"
- "Gift claimed"

## Protocol Mode

Use for architecture, RFP fit, milestones, security, SDK docs, and reviewer proof.

Traits:

- Cream or white backgrounds
- Ink text
- Tables and proof cards
- Clear labels
- Fewer mascots
- Diagram-first layout
- Risk language stays explicit

Example sections:

- RFP mapping table
- System architecture
- Sponsor relay trust boundary
- Test matrix
- Budget and milestones

## Mode Rule

Play Mode invites the user in. Protocol Mode proves the system is real.

Do not let the mascot carry a security claim. Every security or decentralization claim needs a proof card, diagram, or test reference.
