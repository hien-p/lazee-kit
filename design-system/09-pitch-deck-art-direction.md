# Pitch Deck Art Direction

## Slide Structure

1. Lazee Kit title
2. C-address onboarding problem
3. Why this RFP matters
4. What Lazee Kit ships
5. Demo flow
6. Architecture
7. Why better than wallet-only or funding-only approaches
8. Security model
9. Milestones
10. Stellar ecosystem impact
11. Ask and close

## Visual Rules

- One idea per slide
- Large display type
- Cream, sky, or pink backgrounds
- Mascot only on emotional beats
- Architecture slides use Protocol Mode
- Keep budget and architecture on separate slides
- Use proof cards instead of long paragraphs

## Key Slide Concepts

Problem slide:

- Left: crypto-native first minute with seed phrase, XLM, account type, fees
- Right: Lazee first minute with passkey, sponsor, claim

Architecture slide:

- Show user, app, SDK, relay, contracts, indexer, Stellar network
- Label trust boundaries clearly

Impact slide:

- C-address adoption
- Stablecoin payments
- Developer velocity
- Safe automation
- Open-source public good

Close slide:

- Lazee Sun rock-on state
- One ask
- Three proof outputs: demo, SDK, mainnet pilot
